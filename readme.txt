ניהול עדכוני חדשות מקצועיים (טקסט, תמונה, אודיו ווידאו) עם ווידג'ט אלמנטור מלא עיצוב, במגוון פריסות.

== Description ==

התוסף מוסיף סוג תוכן ייעודי לניהול עדכוני חדשות מקצועיים, כולל:

* ממשק ניהול נעים לשימוש עם תיבת מדיה לאודיו ווידאו (קובץ מועלה או קישור חיצוני), תגי מדיה ברשימת הפוסטים, ווידג'ט לוח בקרה ומדריך שימוש מובנה.
* קטגוריות לעדכונים, לסינון תצוגה בכל ווידג'ט בנפרד.
* ווידג'ט Elementor ("עדכוני חדשות מקצועיים") עם 4 פריסות:
  * **פיצול** – שתי תמונות (רבע מהשטח כל אחת) עם רשימת כותרות נעה ביניהן.
  * **טיקר / רשימה** – רשימת כותרות נעה ברוחב מלא, עם תמונות ממוזערות.
  * **גריד כרטיסיות** – תצוגת רשת רספונסיבית.
  * **קרוסלה** – גלילה אופקית עם חצים, נקודות ניווט וגלילה אוטומטית.
* לחיצה על כותרת עדכון פותחת פופ-אפ עם התוכן המלא, כולל תמונה, אודיו ווידאו.
* קצב הגלילה בפריסות הנעות, כמו גם כל הצבעים, הטיפוגרפיה, הרווחים והעיצוב – נשלטים במלואם מתוך עורך אלמנטור, ללא צורך בקוד.

== Installation ==

1. העלו את תיקיית התוסף אל `wp-content/plugins/`.
2. הפעילו את התוסף מתוך "תוספים" בלוח הבקרה.
3. ודאו כי Elementor פעיל.
4. עברו ל"עדכוני חדשות" בתפריט הצד כדי להוסיף עדכונים, ולמדריך השימוש המובנה להוראות מפורטות.
5. פתחו עמוד לעריכה באלמנטור וגררו את הווידג'ט "עדכוני חדשות מקצועיים" מקטגוריית "חדשות מרכז".
